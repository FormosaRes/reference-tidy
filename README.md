# 文獻庫整理與引用核對

網頁：https://formosares.github.io/reference-tidy/

匯入 EndNote、Zotero 的文獻庫（XML、RIS、BibTeX、CSL JSON，或 EndNote 直接輸出的書目文字），合併重複、列出來源之間不一致的欄位、向 Crossref 核對，再依任何期刊的格式（Zotero 樣式庫）排出文獻目錄；也能核對論文正文的文內引用（英文與中文）。

所有處理都在瀏覽器裡完成，檔案與文字不會上傳。期刊格式來自 [Zotero Style Repository](https://www.zotero.org/styles)，排版使用 [citeproc-js](https://github.com/Juris-M/citeproc-js)。

這個 repo 只放建好的單一檔案 `index.html`。
